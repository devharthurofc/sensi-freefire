# Proposal: Redesign Cyber Futuristic AIMZY

## What
Redesign completo do site AIMZY, transformando-o em uma plataforma gaming futurista, premium e extremamente moderna.

## Why
- Imagem profissional e moderna
- Experiência de usuário premium
- Diferencial visual no mercado
- Atração de clientes VIP

## Scope
- Nova paleta de cores (Preto + Roxo Neon + Ciano)
- Background futurista com partículas
- Hero Section com animações
- Cards de planos com glassmorphism
- Cursor personalizado
- Voz feminina de boas-vindas
- Animações de scroll
- Navbar responsiva
- Performance otimizada

## Preserve
- Todas as funcionalidades existentes
- Login/cadastro
- Gerador de sensi
- Sistema de KEYs
- Painel admin
- Banco de dados
- APIs
